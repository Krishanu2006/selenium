## Assignments

### Assignment 1 – Basic Selenium Selectors
Contains Selenium automation scripts demonstrating the use of basic element selectors.

### Assignment 2 – CSS Selectors
Contains Selenium scripts using CSS selectors to locate web elements.

### Assignment 3 – CSS Wildcard Selectors
Contains Selenium scripts demonstrating the use of wildcard techniques with CSS selectors.

### Assignment 4 – CSS Child/Nested Selectors
Contains Selenium scripts demonstrating how to locate child and nested web elements using CSS child selectors.
