# Assignment-1.3

## Selenium Web Element Identification and CSS Selectors

This assignment is about identifying elements on a web page and using Selenium to work with them.

The work is divided into four parts.

### Assignment 1

In this part, different types of web element locators are used to identify elements on the practice webpage. The aim is to understand how Selenium can find elements using their HTML information.

### Assignment 2

This part focuses on identifying multiple elements of the same type. The elements are collected and their information is displayed using Python.

### Assignment 3

This part introduces CSS selectors in Selenium. The purpose is to understand how CSS can be used to identify elements, including cases where part of an attribute value is used.

### Assignment 4

This part focuses on CSS child selectors. The aim is to understand how elements can be identified based on their position inside another element.

## How the Assignment Was Done

The assignments were completed using Python, Selenium WebDriver and Microsoft Edge. The Rahul Shetty Academy Automation Practice page was used as the practice webpage.

The elements were first checked in the browser's Developer Tools to understand their HTML structure. The required Selenium locators and CSS selectors were then used in Python and tested by running the programs.

The code is kept simple so that each assignment can be understood separately.
