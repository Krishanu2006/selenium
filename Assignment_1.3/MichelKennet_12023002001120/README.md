## Description 
This repository contains Python automation scripts for Selenium WebDriver exercises covering web element locators, multi-element processing, and CSS selectors.

- **Task 1 (Web Element Identification)**: Demonstrates locating single web elements using 5 distinct Selenium locator strategies (`By.ID`, `By.NAME`, `By.CLASS_NAME`, `By.TAG_NAME`, `By.LINK_TEXT`).
- **Task 2 (Multiple Element Identification)**: Uses `find_elements()` to retrieve lists of elements, extracting link text from `<a>` tags and toggling multiple checkboxes in loops.
- **Task 3 (CSS Selector Challenge)**: Implements attribute wildcard selectors (`^=` starts-with, `*=` contains, `$=` ends-with) to interact with dynamic input fields.
- **Task 4 (Child Nodes Using CSS)**: Demonstrates DOM hierarchy navigation using CSS direct child (`>`), descendant (space), and index position (`:nth-child`) selectors.

### Environment & Technologies
- **Language**: Python 3.10
- **Automation Framework**: Selenium WebDriver & WebDriver-Manager
- **Browser**: Google Chrome & ChromeDriver
