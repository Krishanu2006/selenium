## Description 
This project contains Selenium WebDriver automation exercises completed using Python. 
The assignments focus on identifying and interacting with web elements using different Selenium locator strategies and CSS selectors.

The first assignment question is based on Web Element identification. The implemented elements used for identification are:
- `By.ID`
- `By.NAME`
- `By.TAG_NAME`
- `By.LINK_TEXT`
- `By.CLASS_NAME`

The second question focuses on multiple element identification.
I used `find_elements()` to locate multiple elements on a webpage and iterated through the returned WebElement list.

The third question was based on CSS Selector.
I implemented CSS selectors to locate elements using:
- ID selectors
- Class selectors
- Attribute selectors
- Wildcard selectors (`^=`, `$=`, `*=`)

The fourth question required finding child nodes using CSS.
I used CSS descendant and child selectors to locate elements based on their relationship within the HTML DOM.

These were all done using the following technologies:
- Python
- Selenium WebDriver
- Google Chrome
- ChromeDriver
